Device Tree for TECNO Spark 20 (KJ5)
====================================

The TECNO Spark 20 (codenamed _"KJ5"_) is a budget smartphone from TECNO.
It was released in February 2024.

| Basic                   | Spec Sheet                                                                                                                     |
| -----------------------:|:------------------------------------------------------------------------------------------------------------------------------ |
| CPU                     | Octa-core (2x2.0 GHz Cortex-A75 & 6x1.8 GHz Cortex-A55)                                                                        |
| Chipset                 | MediaTek MT6769 Helio G85 (12 nm)                                                                                              |
| GPU                     | Mali-G52 MC2                                                                                                                   |
| Memory                  | 4/8 GB RAM                                                                                                                     |
| Shipped Android Version | 13.0                                                                                                                           |
| Storage                 | 128/256 GB                                                                                                                     |
| Battery                 | Non-removable Li-Po 5000 mAh battery, 18W                                                                                      |
| Display                 | IPS LCD 90Hz, 6.6"                                                                                                             |
| Camera (Back)(Main)     | 50 MP, f/1.6, PDAF                                                                                                             |
| Camera (Front)          | 32 MP                                                                                                                          |
