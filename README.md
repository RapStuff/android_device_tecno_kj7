# Android Device Tree for Tecno Spark 20 Pro+ (kj7)

The Tecno Spark 20 Pro+ (codenamed _"kj7"_) is a mid-range smartphone from Tecno.
It was released in February 2024.

| Basic                   | Spec Sheet                                                                                                                     |
| -----------------------:|:------------------------------------------------------------------------------------------------------------------------------ |
| CPU                     | Octa-core (2x2.2 GHz Cortex-A76 & 6x2.0 GHz Cortex-A55)                                                                        |
| Chipset                 | MediaTek Helio G99 Ultimate (6 nm)                                                                                             |
| GPU                     | Mali-G57 MC2                                                                                                                   |
| Memory                  | 8 GB RAM                                                                                                                       |
| Shipped Android Version | 14.0                                                                                                                           |
| Storage                 | 256 GB                                                                                                                         |
| Battery                 | Non-removable Li-Po 5000 mAh battery, 33W Fast Charging                                                                        |
| Display                 | AMOLED, 120Hz, 1000 nits (peak), 6.78 inches, 1080 x 2436 pixels                                                               |
| Camera (Back)(Main)     | 108 MP, f/1.8, (wide), 1/1.67", 0.64µm, PDAF                                                                                   |
| Camera (Front)          | 32 MP, f/2.2, (wide)                                                                                                           |
